# Мой день

Личное приложение: задачи с напоминаниями, мысли по разделам, бюджет.

- `den/` — само приложение. Открывается по адресу https://danuhappy.github.io/Newday/den/
- `den-server/` — сервер (Cloudflare Worker «moy-den»). Выкладывается сам через GitHub Actions
  (`.github/workflows/den-server.yml`) при каждом изменении этой папки. Подробности — в `den-server/ИНСТРУКЦИЯ.txt`.

Перенесено из репозитория Danuhappy/tral вместе с историей изменений.
